# 법인세 세무조정 검색 엔진 MVP 기능명세서

## 1. 제품 목표
- 대상 사용자: 법인세 세무조정 실무를 수행하는 회계사/세무사
- 핵심 가치: 정확한 근거(법령, 행정해석, 판례/심판례)를 빠르게 찾고, 원문과 함께 검토 가능한 형태로 제공
- 비목표: 초심자 대상 세무/회계 개념 설명 중심 서비스

## 2. MVP 범위
- 문서 유형
  - 법령: 법인세법, 시행령, 시행규칙, 조세특례제한법(법인세 연관 조문)
  - 행정해석: 국세청 예규/해석사례, 기획재정부 유권해석(가능 범위)
  - 판례/결정례: 대법원, 조세심판원 우선
- 기능 범위
  - 하이브리드 검색: 키워드(BM25) + 의미검색(Vector)
  - 재랭킹: 상위 후보 정밀 정렬
  - AI 요약 섹션: 출처 인용 기반 요약
  - 검색 결과 섹션: 관련 문서 목록, 필터/정렬, 원문 보기

## 3. 사용자 시나리오
1. 사용자가 쟁점 질의를 입력한다.
2. 시스템이 하이브리드 검색으로 후보 문서를 수집한다.
3. 재랭킹으로 관련도 상위 결과를 정렬한다.
4. 상단에 인용 기반 요약을 보여준다.
5. 하단에 문서 목록을 보여주고, 항목 클릭 시 원문 전문으로 이동한다.

## 4. 화면 요구사항

### 4.1 검색 화면
- 입력창
  - 자연어 질의
  - 예: "업무무관자산 관련 지급이자 손금불산입 계산 기준"
- 고급 옵션
  - 문서유형 필터: 법령/행정해석/판례
  - 기준일(법령 효력시점)
  - 기관 필터
- 결과 레이아웃
  - 섹션 A: AI 요약 답변
  - 섹션 B: 검색 결과 목록

### 4.2 섹션 A: AI 요약 답변
- 구성
  - 핵심 결론 요약(3~6줄)
  - 적용 요건/예외
  - 쟁점별 근거 문서 인용(번호)
- 인용 표기
  - 각 요약 문장 또는 문단은 최소 1개 출처와 연결
  - 출처 클릭 시 해당 문서의 근거 위치로 이동
- 안전장치
  - 근거 부족 시 "근거 부족" 상태 명시
  - 현행/구법 혼재 시 경고 배지 표시

### 4.3 섹션 B: 검색 결과 목록
- 카드 필드
  - 제목
  - 문서유형
  - 출처기관
  - 문서일자/시행일
  - 관련도 점수
  - 매치 스니펫
- 동작
  - 정렬: 관련도, 최신순, 권위순
  - 필터: 문서유형, 기관, 기간, 현행/구법
  - 원문 열기: 전문/조문 전체 확인

### 4.4 원문 상세 화면
- 좌측: 원문 전문(하이라이트 포함)
- 우측: 자동 요약, 키워드, 문서 메타데이터
- 내비게이션
  - 법령: 조/항/호 단위 이동
  - 판례: 사실관계/쟁점/판단/결론 섹션 점프

## 5. 검색 파이프라인 요구사항
1. 질의 전처리
   - 법령표기 정규화(예: 제19조제1항 -> 제19조 제1항)
   - 동의어 확장(손금산입/비용인정 등)
2. 1차 검색
   - 키워드 검색 상위 K1
   - 벡터 검색 상위 K2
3. 후보 통합
   - 중복 제거 및 문서 단위 병합
4. 2차 재랭킹
   - Cross-Encoder 또는 동급 모델로 상위 N 정렬
5. 응답 생성
   - 상위 M개 문서를 근거로 요약 생성
   - 요약 문장-근거 문서 매핑 필수

## 6. API 명세 초안

### 6.1 POST /api/search
- 요청
```json
{
  "query": "업무무관자산 지급이자 손금불산입",
  "filters": {
    "docTypes": ["statute", "ruling", "case"],
    "authority": ["nts", "scourt", "tt"]
  },
  "sort": "relevance",
  "asOfDate": "2026-05-20"
}
```
- 응답
```json
{
  "summary": {
    "text": "...",
    "citations": [
      {"id": "doc_123", "anchors": ["제27조 제1항"]}
    ],
    "warnings": ["현행/구법 혼재 가능"]
  },
  "results": [
    {
      "id": "doc_123",
      "title": "법인세법 제27조",
      "docType": "statute",
      "authority": "moef",
      "date": "2025-01-01",
      "score": 0.92,
      "snippet": "..."
    }
  ]
}
```

### 6.2 GET /api/documents/{id}
- 응답: 문서 메타데이터 + 원문 전문 + 섹션 인덱스

### 6.3 POST /api/feedback (선택)
- 목적: 검색 품질 개선용 사용자 피드백 수집

## 7. 비기능 요구사항
- 성능
  - P95 응답시간 4초 이내(요약 포함)
  - 검색 목록 선응답(스트리밍) 고려
- 가용성
  - 업무시간 SLA 99.5% 목표
- 보안
  - 감사 로그 저장(질의, 선택 문서, 응답 버전)
  - 접근 제어 및 암호화 적용
- 추적성
  - 임베딩/재랭킹/요약 모델 버전 기록

## 8. 수용 기준 (Acceptance Criteria)
- 요약 문장 인용률: 100%(모든 요약 문장에 출처 연결)
- 검색 정확도: 골든셋 기준 Precision@5 목표치 달성
- 원문 접근성: 모든 검색 결과에서 1클릭으로 전문 확인 가능
- 현행성: 법령 개정 반영 SLA 내 인덱스 업데이트 성공

## 9. 제외 범위 (MVP)
- 다국어 지원
- 사용자별 지식 그래프 개인화
- 자동 신고서 작성/세무조정 분개 제안
