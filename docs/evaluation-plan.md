# 검색/요약 평가셋 및 품질평가 설계

## 1. 평가 목적
- 실무 질의에 대해 근거 문서를 정확히 찾는지 검증
- 요약이 근거를 벗어나지 않고 실무 의사결정에 도움이 되는지 검증

## 2. 평가셋 설계

### 2.1 질의 세트 구성
- 규모: MVP 초기 250문항 권장
- 출처
  - 실제 법인세 세무조정 업무 질의(익명화)
  - 자주 발생하는 쟁점 시나리오 템플릿
- 난이도 분포
  - 단일 근거형 40%
  - 다중 근거 결합형 40%
  - 충돌/예외 판단형 20%

### 2.2 라벨링 대상
- 정답 근거 문서 Top-k
- 정답 근거 섹션(조문/판시요지/해석 결론)
- 허용 가능한 대체 근거(동등 권위 자료)
- 기준일(as_of_date)별 정답 분기

### 2.3 라벨링 절차
1. 1차 라벨: 실무자 A
2. 2차 검수: 실무자 B
3. 불일치 조정: 리뷰어 C 결정
4. 최종 확정: 골든셋 버전 태깅(v1, v2 ...)

## 3. 검색 품질 지표
- Precision@5
- Recall@20
- nDCG@10
- MRR
- Filter Accuracy
  - 문서유형/기준일 필터 적용 정확도

## 4. 요약 품질 지표
- Citation Coverage
  - 요약 문장 중 출처 연결 비율(목표 100%)
- Citation Correctness
  - 연결 출처가 실제 주장 근거인지 정확도
- Groundedness
  - 출처에 없는 주장 비율(낮을수록 좋음)
- Task Helpfulness
  - 실무자가 "판단에 도움됨"으로 평가한 비율

## 5. 자동 평가 파이프라인
1. 테스트 쿼리 입력
2. 검색 결과 저장(후보/최종 순위)
3. 요약 및 인용 매핑 저장
4. 골든셋 비교 점수 산출
5. 리포트 생성(전체/문서유형별/쟁점별)

## 6. 오프라인 벤치마크 실험 설계
- 실험 축
  - A: BM25 only
  - B: Vector only
  - C: Hybrid
  - D: Hybrid + Reranker
- 기대
  - D가 Precision@5, nDCG@10에서 최우수

## 7. 온라인 평가 (베타)
- 대상: 회계사/세무사 10~20명
- 기간: 2~4주
- 핵심 지표
  - 질의당 해결 시간
  - 결과 클릭률(원문 접근률)
  - 재검색률(첫 검색 불만족 간접지표)
  - 사용자 만족도(5점 척도)

## 8. 품질 게이트 (출시 기준)
- 검색
  - Precision@5 >= 0.75
  - Recall@20 >= 0.90
- 요약
  - Citation Coverage = 1.00
  - Groundedness 위반 <= 2%
- 안정성
  - 평가 파이프라인 실패율 <= 1%

## 9. 오류 분석 프레임
- 검색 누락
  - 동의어 누락, 형태소 분석 오류, 기준일 필터 오류
- 오탐 상위노출
  - 재랭킹 피처 부족, 권위도 가중치 미흡
- 요약 오류
  - 근거 충돌 처리 미흡, 인용 매핑 실패

## 10. 운영 루프
1. 주간 배치로 평가 실행
2. 성능 하락 탐지 시 원인 범주 자동 분류
3. 동의어 사전/랭킹 가중치/프롬프트 수정
4. 회귀 테스트 통과 후 프로덕션 반영
